## 🧠 About the Project

**Enumeration Tools & Wordlist** is a personal cybersecurity learning project containing three Bash scripts:

- `Passsec.sh`
- `SCanneR.sh`
- `saFepass.sh`

The repository supports practical Linux command-line learning, shell scripting, and experimentation with security-related utilities.

The scripts are maintained as part of an ongoing cybersecurity learning journey. Their precise features, options, and dependencies should be confirmed by inspecting each script's source code.

### Why this project?

Cybersecurity requires both theoretical knowledge and practical experience. Small command-line projects help learners understand how scripts accept input, process data, handle errors, and produce results.

This repository provides a place to develop, test, document, and improve Bash utilities in an authorized lab environment.

## 🎯 Project Goals

- Improve Bash scripting and Linux administration skills.
- Learn to structure and maintain security-related scripts.
- Practice
